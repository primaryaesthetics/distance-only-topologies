# Claims

The authoritative list. Nothing in this repository is a claim unless it appears
here with an evidence pointer that resolves. `scripts/check_claims.py` verifies
every row and fails if a pointer is dead.

The rows are those the paper cites in its source and the rows their statements
refer to. IDs are therefore not contiguous; an ID is never reused.

## Format

| Field | Meaning |
| --- | --- |
| ID | `C-NNN`, never reused, never renumbered. |
| Statement | What is asserted, precisely enough to be wrong. |
| Model | One of the models below. |
| Evidence | `experiments/<dir>`: a recorded run with its `manifest.json`. |
| Status | `active` or `superseded by C-NNN`. |

A claim is never edited in place once it has a resolving pointer. To correct
one, mark it superseded and add a new row.

## Models

- `comparison-addition`: Edge weights are opaque reals. The only permitted operations on them are binary comparison and addition: no arithmetic on their representation, no hashing, no bucketing by numeric value.
